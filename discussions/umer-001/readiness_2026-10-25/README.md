# UMER-001 R4：资源准入、数据选型与独立筛查

日期：2026-10-25。协调者：本机 Codex。研究输入为 [R3-C 总结](../decision_2026-10-25/README.md)，版本 e4e01f4。用户本轮要求推进资源核验与诊断协议，并补充两点：暂时无人类审核者，可以安排独立新会话；不必局限 PHEME/Ma-Weibo 或随机五折。

**本轮将最终数据集与划分重新开放。** 研究目标保持：社会反馈变化下减少非任务相关反应的影响，同时保留事件相关信息；普通平均精度提升不能单独承担贡献。

## 本轮交付

- [数据候选与可得性](dataset_candidates.md)：按一手来源、实际文件与标签含义比较；已有人工标签优先，但不同标签不强行等同。
- [诊断协议 v0.2](protocol_v0_2.md)：测量、输入重建、数据/任务适配与停止条件；是可审阅草案，尚未冻结最终数据与主实验。
- [独立 agent 筛查说明](review_guide.md)及[返回格式](response_schema.json)：用于私下交接的小型探索性样例包，不能作为人工 gold。

本地已准备两语料各 6 个宿主上下文、每个两对候选，共 24 对的盲评试核包。它在用户开放数据范围之前开始准备，仅试核流程，不绑定最终 benchmark。样例、源标识映射、逐项返回及操作核验记录不在公开仓库发布。公开文件不包含连接、部署、实时设备状态或原始评论。

## 建议执行顺序

先核实带既有人工标注的候选资源，再选一个主任务数据与必要的辅助测量资源；不同时铺开多套完整训练。独立新会话可并行试核本地包，记录机器间的分歧与弃权，不直接投票决定科学方向。

优先检查 RumourEval 2019 的事件判断和人工回复立场能否支撑最小验证，另用具有明确社会行为标签的资源覆盖其缺口。这里的优先是资源准入顺序，不代表方法或最终数据已经选定。若任务标签改变，须重新建立对应基线，不能直接套用原二分类检查点。

本轮未运行分类模型前向、训练、推理 API 或正式效果实验，没有重写论文或历史结果。服务器操作与资源定位记录仅留本地；本公开版本只交代科研输入与协议边界。
