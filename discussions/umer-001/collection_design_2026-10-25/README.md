# UMER：真实采集与受控构造的数据方案 v0.1

> 2026-10-25更新：本文保留为历史方案，其中Muse首次执行任务指引已由[事实事件与反馈现象驱动的v3](../collection_events_2026-10-25/README.md)替代。用户尚未启动采集；不要直接执行旧任务书。

日期：2026-10-25。依据 [R4-S 核对结果](../review_results_2026-10-25/README.md)，版本 815b60b。用户要求增加真实采集，可把有界任务交给 Muse 执行。本文件是方案，不表示已完成采集、标注效度或实验验证。

## 推荐形式

以“主张/新闻事件—平台源帖—真实回复子树—观测快照”为层级，建立三部分数据，分别报告，不混合成一个平均指标。

| 部分 | 内容与用途 | 关键约束 |
| --- | --- | --- |
| 既有标注基准 | 基线训练、协议对照及已有人工标签锚点 | 保留原任务含义；rumor/non-rumor 与 true/false/unverified 不互相直接映射 |
| 新采集自然集 | 未改写的源帖、回复父链、观测时间和独立核验记录；用于现实场景检验 | 同时包含普通讨论与自然偏移；真假依据与评论行为标签分开，未验证者不进入对应主评估 |
| 真实底座上的配对构造集 | 对真实线程作有记录的反馈变化，检验特定机制并可用于训练增强 | 每个修改显式标记；不声称是自然发生；原主张、任务语义与标签保持条件逐项核验 |

已有数据或 P0/P1 试采只要被用于设计，就记录接触历史；正式自然确认集另按冻结规则采样，避免把反复看过的样例称为未接触测试。自然演变前后比较是观察性分析，不自动成为随机干预或因果证据。

## 平台选择：科研适配与访问事实分开

**建议首批评估微博、贴吧、知乎；最后只选一个主平台和一个必要补充平台。** 这是文字/回复结构与研究成本的选择建议，不表示三者已获采集权限或登录后一定可完整获取。

- 微博：主平台候选，适合对照既有中文工作；先核实允许的访问/采集渠道、公开源帖与评论/转发关系。官方服务协议对未经许可的自动化抓取有明确限制；账号登录不替代该权限。官方开放平台另有 OAuth 与接口范围，不能假定普通登录可取得任意完整评论。[服务协议](https://m.weibo.cn/c/regagreement?from=h5&lang=zh_CN)、[开放平台](https://open.weibo.com/cli/quickstart)
- 贴吧：文字楼层及楼中楼的补充候选。官方隐私政策说搜索、浏览可无需登录；没有据此确认完整分页、历史帖子或回复父链可采。其早期开放 API 页面不能当作当前接口承诺。[官方隐私政策](https://tieba.baidu.com/tb/mobile/wisemainstatic/secretright.html?noshare=1&page=page1)
- 知乎：较长讨论的补充候选。问题、答案、评论是不同层次，不能一概当“源帖—回复”；须明确当前主张来自问题还是具体答案。官方说明登录后的阅读与互动功能，但网页与其他端功能可不同，实际展开范围须试核。[官方指引](https://www.zhihu.com/term/privacy)
- 小红书：可在文字足够表达主张、图片上下文可保留时补充；本轮不承诺实际访问范围。当前协议页未能读取全文，不凭旧存档断言当前采集许可。[官方协议入口](https://agree.xiaohongshu.com/h5/terms/ZXXY20220331001/-1)
- 抖音：初期后置，避免把视频缺失当作离题证据；若后续纳入，需要视频内容、转写及其误差。官方协议限制未经授权自动化接入和采集，不能因已有账号就默认可批量抓取。[用户协议](https://www.douyin.com/agreements/?id=6773906068725565448)
- X/Twitter：暂不承担首批新采集。官方称公开帖可由未登录者查看，但这不足以保证完整搜索、分页与回复获取；当前没有对实际采集器进行完整性测试。英文可先用已发布数据包，后续再核实正规渠道。[公开/受保护帖子](https://help.x.com/en/safety-and-security/public-and-protected-posts)、[API 说明](https://help.x.com/en/rules-and-policies/x-api)

遇到登录、验证码、访问拒绝或配额时记录状态，不绕过；不把热门排序、折叠、删除或不可见内容造成的缺失解释成完整线程。平台显示评论数也不等于可恢复节点数，二者比值不是真实覆盖率。

## 采集什么

先定位能明确表述的事实主张，并记录独立核验材料，再寻找原始传播/讨论帖。辟谣或纠正文章主要作为标签证据，不能一律拿它替代原始传播帖。单纯观点、身份争吵、无可辨认命题的分享可留在行为辅助池，不强行赋事件真假标签。

初始覆盖公共事件、科学科普、消费/产品等不同主题。既要保留正常讨论，也要覆盖借题转向、群体争执、情绪反应及重复传播；不只搜索“水军/带节奏”来决定全部样本。先按冻结取样顺序取基底，再单独标记现象富集样本，不能用后者估计自然发生率。

每条记录至少保留：
- 原始可见文字与其来源、实际采集时间、发布时间/时间精度、平台及排序方式；
- 源帖、实际父回复、祖先链与关系类型；缺父链不得猜挂到根节点；
- 主张、新闻事件、线程和快照的层级标识及缺失原因；
- 外部核验结论原文、来源、日期与主张对应关系，和它是否只用于标签；
- 原始片段/快照审计依据与采集方法，另存去标识工作副本。

用户名采用宿主内稳定匿名别名，保留对象对应，不能全部替成同一个占位符。原始映射受限保存，不额外采集作者画像、私信、通讯录或登录凭据。原始数据、逐条来源及样例继续不进入公开仓库。

## 标签与效度

真实采集解决来源真实性，不自动解决标签真实性。采集器只记录可观察内容和核验出处；后续分别处理事件核验、对主张的立场、反应对象、相关性、情绪和重复情况。comment、强情绪、攻击性与离题不互为同义词，也不据此判定机器人、水军或恶意动机。

如果只有核验结论，先保存原结论与时间，不自动转换原 UMER 的 rumor 标签；任务映射未闭合者进入诊断池。行为标签可先做独立机器筛查；已有人工标签只校准其对应维度，不能把其他维度或多数票升级成 gold。

构造集在此基础上选择少数清楚可定义的变化，并保留正常相关补充、相关但情绪强烈的反应作对照。所有变体跟随原主张共组；生成规则/模板和自然确认集分别留出。对照构造思路可参考 [CheckList](https://aclanthology.org/2020.acl-main.442/)；[AARD](https://aclanthology.org/2021.findings-acl.118/) 已研究生成对抗回复，生成本身不是新颖性。

## 分阶段且有界

[Muse 单文件任务书](MUSE_COLLECTION_TASK_v1.md)包含完整目标、范围、停止条件、内嵌字段和验收要求，无需另附研究目录。

1. P0：三个候选平台各至多两条线程，每线程含源帖/祖先在内至多 30 个节点，总计至多 180 个节点；核验渠道、内容展开、父链及时间字段。
2. 仅当 P0 有适合且允许的渠道时，Muse 可按任务书自动进入 P1：目标 20 个互异主张、至多 40 条线程、每线程至多 100 节点，建立可审查的小型真实池；新闻组依赖另记。P0 合格记录计入 P1，整个任务不超过 40 线程/4,000 节点。只取明确可见内容，不要求凑满或补造。
3. 根据实际可采率、标签出处、父链完整度与主题覆盖决定正式规模；20 个主张不是论文功效或工作量保证。冻结正式协议后才采未接触确认集，并确定模型适配与效果诊断。

当前未登录任何用户账号、未执行社交平台采集、未创建 Muse 后台任务、未调用生成或分类推理；本轮交付为设计与可转交文件。

## Muse 能力核实

Muse 官方介绍其有独立云电脑、文件系统、终端和浏览器，可运行有界研究流程并交付文件。这支持交接形式，不保证它在每个平台的实际登录、访问或采集权限。任务输出写在它自己的工作区，用户下载后再交回本机会话；不要求 Muse 访问本机磁盘或计算环境。[官方介绍](https://introducing.muse.ai/)、[产品页](https://muse.ai/?return_to=%2Fplatform)
