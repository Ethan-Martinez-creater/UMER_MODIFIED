## 任务与标签保持分开

目标仍是事件级谣言检测在反馈变化下的可靠性，游戏口碑和情绪分类不是目标。合格事实事件里的真实评价可作为反馈保留，纯评价线程不采成事实事件。

事实主池要求supported/refuted及充分对应证据；mixed/unresolved/uncheckable只留候选台账，不扩采成主事件。真假结论与原UMER的rumor/non-rumor仍分列。本次未冻结新语料的二分类映射，因此Muse不得擅自将false映射rumor或true映射non-rumor。交付是供项目审计和统一标注的采集候选集，尚非可直接训练/评测的金标准；这是明确剩余工作，不能宣称已满足最终标签要求。

反馈只作可追溯的agent预审，不以文本推断真实玩家身份、水军、机器人或动机。不训练或前向，不能声称模型被带偏。跨线程/时段观察不自动构成因果对照。
