## 1. 当前目标与用户新增背景

用户明确：最终论文需要能够回应导师对 motivation 与创新不足的意见。**常规谣言检测二分类上的 Accuracy/F1 提升，不能独自承担论文贡献。** 可以保留二分类；必须说明实际研究问题、相对已有工作的实质增量，以及可验证的新能力或新认识。增加模块、改变命名、扩大题目或改划分，均不能自动满足目标。

在 Codex R3 提出“可操纵社会反馈”后，用户补充：范围不应局限于直接说“这是谣言”“已经证实”的评论，也不应只限复制。水军、机器人、群体历史矛盾、带节奏或与当前事件关系较弱的言论，都可能改变评论的情绪、议题或互动结构，并进而影响模型。自然发生的群体争执与情绪变化也值得考虑。

这是**用户希望共同考虑的场景扩展**，不是已测得的 UMER 缺陷，也不是三方对 Codex 提案的采纳。我的原 R3 共享去重复机制只覆盖其中一个子场景，不能直接声称覆盖上述全部情况。

适合本轮比较的问题表述是：**社会反馈受到操纵，或其议题、情绪和参与结构发生变化时，模型能否仍然可靠地利用与当前事件有关的信息？** 该表述暂作候选问题框架；可接受、修改或否决。

## 3. 本轮共同判断标准

请同时考虑三份 R3 与用户新增背景，不预设必须选 Codex，也不以多数票定方向。

1. **问题与贡献**：场景是否具体且值得研究？如果干净集总体指标持平，仍留下什么可重复的新认识或能力？改变评价指标本身不算新增能力。
2. **与直接前作的差异**：区分已有方法、拟研究增量和未核实空白；“未读到”“未命中”不等于不存在。对自己 R3 中过强的说法明确修正。
3. **机制与证据**：能否提出可被推翻的核心机制？不能把相关性当有害原因，把模型置信度当可靠性真值，或以注意力图代替机制证据。
4. **数据和成本**：共享包是阅读快照。原数据映射、完整代码、检查点、群体/机器人标注等要区分已证实可用与待核实；重训、人工核验、攻击评价和基线复现都计入成本。
5. **可收敛性**：选择一个推荐问题、至多一个备选，列一项最有决定价值的首项验证及停止条件。允许结论为“当前候选都未达到机制准入”。

## 4. 必须澄清的关键边界

- `rumor / non-rumor` 不是事实真/假的同义词；本项目不因讨论社会反馈而变成开放事实核查系统。
- 强烈情绪、反对意见、离题、重复、协同、自动化和恶意意图是不同维度。正常质疑与纠错可能有信息价值；词面相似度不能直接定义相关性或可信度。
- 机器人/协同/群体冲突的传播研究，只能支持现实动机，不能证明 UMER 已受其影响。没有长期账号历史或独立标签时，不承诺识别机器人或还原参与者动机。
- 三路 UMER 共用事件帖子，但线性融合没有声明概率独立或各路同等可靠。不能凭架构就宣称“独立证据重复计数”已证实。
- 图含节点语义；检索查询来自节点语义统计，并不直接来自四个 DeBERTa 截断视图。正式融合的固定检查点边际变化可作加法分解，不能据此宣称超加性融合交互。
- Zcode R3 的试点话题数与训练次数需统一；其信息类型假设与 full/no_text/no_memory 消融能否对应也需说明。三个配置并未严格分离“纯结构”与全部语义。
- 网页端 R3 的“同内容安全变换”需要定义；片段集合相同不自动表示语义等价。两次前向的预算、累计回复曝光与 SAM 必须能公平匹配。
- 旧随机五折与 LOTO/时间切分不是同一协议。旧 OOF 测试标签已用于方向启发；后续不能重新称其为完全未触碰确认集。不同配置重训消融也不等于逐事件的直接因果归因。

这些是本轮需回答的检查点，不是预先否决某份提案的裁决。

## 5. 交付格式

每方提交一份约 800–1500 中文字的评议（来源可另列），直接在 Issue #1 评论：

`[participant | R3-C | 汇总与定向评议]`

建议结构：

1. **推荐及变化**：推荐哪个问题、是否修订自己 R3、为什么；至多一个备选，也可判定均未准入。
2. **贡献检验**：用三句话写出“真实问题—待研究机制—成功后的新增能力/认识”；说明总体指标持平时靠什么成立。
3. **交叉评价**：对另两份 R3 各给最强支持、关键质疑；结合新增场景说明能覆盖什么、不能覆盖什么。
4. **前作边界**：优先复核 1–2 篇最直接方法，标注已读范围；列出因此保留或撤回的新颖性说法，无需再做宽泛综述。
5. **唯一首项验证**：输入和可用性、是否需人工核验/新前向/重训、主要对照、开发/确认边界、继续与停止条件，以及预计工作量。只设计，不执行。

先读全部固定 R3 与此材料，形成自己的本轮意见后再看其他 R3-C，减少跟随。若工具无法发 Issue 评论，将完整 Markdown 交给用户原样代发并注明来源，不需要再建 PR。只写自己范围，不覆盖或移动他人文件。

三份 R3-C 收齐后，协调者写一次对照汇总：共同事实、首选/备选、保留分歧、缺的证据、首项验证及否决条件。最多再做一轮针对性澄清；没有关键新证据时不继续滚动发散。最终由用户决定是否进入相应验证。
