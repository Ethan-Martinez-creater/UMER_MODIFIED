## 0. 结论与边界

**首选：观测覆盖感知的跨视图证据一致性（Observation-coverage-aware View Consistency，暂称 OCVC）**。先检验“两个标签不变的会话视图，在 256-token 限制下是否仍携带可比较的回复证据”；仅当视图实际可观测内容相容时施加强一致性，否则显式区分“回复没有进入输入”和“回复内容导致不同判断”。**该困难目前是代码导出的合理假设，不是已证实的 UMER 失效。** 创新点只有在“现象存在—可观测性区分有效—简单重采样/常规加权不足以解释”三条件均满足时才成立；不能将给 JSD 加权本身写作方法创新。

**至多一个备选：跨话题的近邻证据适用域控制**，但现有记忆分支总增益极弱，应先以低成本诊断决定是否保留。第三个评估候选（早期阶段建模）建议**暂缓**：已有 SWAM/SCSNet 等直接方案，且切换到真正的早期协议会改变目前 240 小时全观察结果的比较意义。三者都不需要 LLM 作为研究主线，不扩成开放事实核查，不重新定义二分类标签。

## 1. 现有模型：先分事实、疑问与新贡献

### 1.1 已确认的基线事实

- **任务**：源帖与 240 小时内回复组成事件，输出 rumor/non-rumor；不是逐事实真伪验证或提前时段检测。PHEME 6,425 事件、其中 source-only 677（10.54%）；Ma-Weibo 4,664 事件、source-only 6。两者保留帖数分别 105,238 / 1,771,329；每事件帖数中位数分别 12 / 236。依据：docs/START_HERE.md §2；docs/UMER_MODEL_ARCHITECTURE.md §§1–2；manuscript/main.tex §4.1（约第 666–740 行）。
- **模型**：图支路（非文本 Set readout 加一层 Transformer）、DeBERTa-v3-large 文本支路、训练折内语义近邻标签库 top-31（温度 0.05），5→2 的线性融合；训练每事件随机两种文本视图，验证测试四视图 logits 平均。文本视图是源帖固定置首的 full/reversed/even/odd；输入 max_length=256。依据：docs/UMER_MODEL_ARCHITECTURE.md §§2–6、§9；reference_code/round_013_joint_trifusion/model.py 第 10–27、117–232、276–375 行；reference_code/round_013_joint_trifusion/run_fold.py 第 100–165、735–775 行；manuscript/main.tex §3.3。
- **优化**：最终 CE、图/文本各 0.15 辅助 CE、视图 JSD 权重 0.5；exact-replay SAM rho 0.05、物理/有效 event batch=4/64。reference_code/regularization.py 第 6–16 行计算无事件条件的视图 JSD；run_fold.py 从外部 round_009 导入 build_event_views，故本仓库仅保留其四视图说明，未单独含原始视图构造函数。论文的文本辅助 CE 公式与源码逐视图 CE 有已登记差异，归入一致性修订，不计为研究创新。
- **严格的现有结果**：事件级分层五折，partition seed=3090、training seed=2000；内层验证决定 checkpoint 和阈值。PHEME Accuracy/Macro-F1/Rumor-F1 = 0.8988/0.8925/0.8666；Ma-Weibo = 0.9689/0.9689/0.9694。PHEME 无文本 0.8601、无 JSD 0.8895、无图 0.8940、无记忆 0.8985（Accuracy）。依据：results/ 六个 summary JSON 的 mean、docs/UMER_EXPERIMENTS.md §§1–4、main.tex §4.3。无 JSD 相差 0.93 个百分点是 **组件移除的总体效果**，不是“覆盖失真”存在的直接证据；记忆增益约 0.03 个百分点，不得解释为稀疏子集已有正效果。
- **对比协议谨慎解释**：PHEME 最强展示基线 MST 0.8691 排除 source-only，Bi-GCN/RAGCL/RRD-N 作者协议在训练/选点时访问测试折；Ma-Weibo RRD-N 仅有 3 折。因此原稿中相对某行的增益不是所有方法在同一严格无泄漏/同样测试总体条件下的因果差异。依据：manuscript/audits/pheme_comparison_metrics_audit.md “Protocol qualifications”；manuscript/audits/maweibo_macro_metrics_audit.md “Reporting rule”。

### 1.2 能合理质疑、却尚未被证实的事

**观察缺口 H0**：full、reversed、even、odd 都不更改事件标签，但在固定源帖置首与 256-token 截断后，不保证每个视图实际观察到相同或足够的回复。对 Ma-Weibo 尤需核实：其中位数为 236 帖/事件，不等于 236 条回复真的进入 256 tokens；对 PHEME source-only 则四视图可能完全一致。事件标签一致不蕴含 **每个截断的输入具有相同可推断性**。需要以实际 tokenized 内容和内层验证日志测量；目前公开仓库未提供逐事件原文、token 化明细和预测，不能声称视图已矛盾/已失效。

**训练目标可能失配 H1**：UMER 无条件地将两视图概率推近。若两个视图因截断而分别缺失不同关键回复，强制预测一致可能压制由新增事实/质疑带来的有用改变；反之适当一致性又能抑制顺序噪声，且现有 0.93pt 消融支持整体上保留 JSD。目标是判断**一致何时适当**，而不是取消一致性或制造反例。

**分布边界 H2**：PHEME 九个新闻话题的事件随机分层五折允许同话题不同事件跨折；它保证事件不重合而非未见话题泛化。训练库排除验证/测试标签是确认的，但不能从此得出语义近邻没有话题依赖。应与跨话题严格留出评估区分。

### 1.3 不应包装成机制贡献

修正文本辅助 CE 和 Set 聚合的论文-代码差异、审计协议限定、复算结果汇总，是**必要论文一致性/透明度工作**；改 tokenizer 长度、换预训练 backbone、简单加 attention、给现有 5→2 头改名字、做更多随机种子，只属控制或工程。源码已经存在 ReliabilityGatedFusion 与 ConditionalResidualFusion（model.py 第 30–114、179–200 行），正式配置虽未启用，但“简单可靠性门控”在本资产里已不是全新候选；提出它必须超过这一直接代码控制和公开前作。

## 2. 最直接近邻：实际阅读后的机制比较

下列状态、页码及局限在 evidence_matrix.md 中逐行记录；**不同原文的分区、标签与数据不可直接比较其绝对指标**。

**N1 — Liang et al., “R-Drop: Regularized Dropout for Neural Networks”, NeurIPS 2021，正式发表。** 阅读官方 PDF §2.1–2.2（p.3 起）与 §3（含语言理解结果）；双 dropout 前向针对**相同输入**使用双向 KL，将随机子模型分布拉近；不处理由于 reply/token-budget 裁切而导致的**输入可观测内容差别**。UMER 已用跨不同序列化的广义 JSD，故“再加双前向一致性”不是独立创新。论文：https://proceedings.neurips.cc/paper_files/paper/2021/file/5a66b9200f29ac3fa0ae244cc2a51b39-Paper.pdf 。

**N2 — Cui & Jia, “Propagation Tree Is Not Deep: Adaptive Graph Contrastive Learning Approach for Rumor Detection”, AAAI 2024，正式发表。** 阅读官方 PDF Method（pp.75–77）、Experiments/Ablation（pp.77–79）。它首先研究树的宽浅结构，以 degree/betweenness/PageRank 重要性控制**图节点、属性、边**的增强概率，根节点不删，用 GCN 表征对比损失；在 Weibo、DRWeibo（二分类）、Twitter15/16（四分类）比较，作者报告十次随机划分平均。它已经占据“重要回复优先保留 + 自适应视图”的宽泛论点。拟议方向若退化为基于树中心度选回复或通用对比增强，**不新**；剩余差异必须是 tokenizer 实际可观测性作为一致性语义的前提，而非再做图增强。论文：https://ojs.aaai.org/index.php/AAAI/article/download/27757/27555 ；代码链接见论文：https://github.com/CcQunResearch/RAGCL （本轮未审代码）。

**N3 — Kang & Yuan, “Early detection of online public opinion rumors for cross-event generalization”, Discover Artificial Intelligence，2026-09-18 正式发表。** 阅读开放全文 §§3.1–3.4、§4.1–4.3。SCSNet 利用回复-源帖/父帖差异、时间、深度估计贡献，软分阶段，以线性更新门控逐阶段决策；它在 PHEME 做话题分离的跨事件评估，并给出 GRU/LSTM/Transformer 同阶段输入对照。其贡献已包括“噪声回复贡献鉴别”“新阶段是否包含新信息”“早期状态一致性”。因此 OCVC 不得声称首次识别回复贡献，也不能直接复制阶段门控。潜在正交点：**固定 256-token 文本视图中“未被输入”与“已输入但低信息”的区分**，以及是否应进行概率一致性，而非传播状态机。注意它 PHEME 跨事件 Macro-F1 82.74% 与 UMER 事件随机五折 89.25% **不可横向排名**。全文：https://link.springer.com/article/10.1007/s44163-026-02227-7 。

**N4 — Guo et al., “SWAM: Adaptive Sliding Window and Memory-Augmented Attention Model for Rumor Detection”, EMNLP 2025，正式发表。** 阅读 PDF §§3.3–3.5、§4.1–4.4（pp.14421–14426），未系统核查全部附录。按传播速率分动态窗口，将前窗节点作 memory，经深度嵌入和多头注意力逐窗更新；TWITTER、DRWeibo 上分析滑窗/深度/attention 和早期检测。这里的 memory 是**事件内的时间窗口状态**，不是 UMER 用训练事件标签建立的跨事件近邻库；不得二者混同。它是第三方向的强直接前作，而不是 OCVC 贡献的缺失证明。PDF：https://aclanthology.org/2025.emnlp-main.729.pdf 。

**N5/N6 — Ren et al., “Cross-Topic Rumor Detection using Topic-Mixtures”, EACL 2021（正式）；Ran et al., “A metric-learning method for few-shot cross-event rumor detection”, Neurocomputing 2023（正式）。** 前者阅读官方 PDF §§3–4（p.1536 的 topic-mixture 表示和 PHEME 话题留出）；后者阅读出版商开放的 abstract、Methodology/Datasets 等正文预览（全文其余受访问限制）。前者用话题分布混合表示改善跨主题分类，后者在 PHEME5/9 利用历史事件预训练和 episodic 原型/关系度量适应少样本新事件。两篇直接削弱了“跨话题/跨事件检索是新概念”的说法；备选若成立，需瞄准训练折参考库**适用域与引用置信度**的可诊断性，而非重新做 topic mixture / metric learning。链接：https://aclanthology.org/2021.eacl-main.131.pdf 、https://doi.org/10.1016/j.neucom.2023.02.044 。

## 3. 候选一（首选）：观测覆盖感知的一致性机制

1. **问题（具体场景）**：长对话或重复度高的事件，有效文本预算远少于总回复；不同合法序列化在 tokenizer 后可能暴露不同内容。部署时决策不应仅因回复排序而变动，但又应允许真正新增/不同的证据改变决策。这同时涉及不变性与对新信息的敏感性。
2. **UMER/前作缺口**：UMER 使用四种固定次序/奇偶取样，训练二视图无条件 JSD；R-Drop 正则 dropout 模型、RAGCL 构造重要性图视图、SCSNet 处理增量时间阶段，三者尚不能自动回答 **UMER 被截断的视图是否有可比较的信息基础**。不是声称所有其他论文均忽视 token coverage。
3. **可推翻假设与可能机制**：先对每个已 tokenized 视图建立“实际回复覆盖集合、覆盖 token 预算、与另一视图的重合度/语义差异”统计；区分观测层缺失与已观测的预测分歧。若诊断成立，训练保持相同 CE、SAM 和骨干，对强同证据视图施加完整一致性；对明显不等价的观察对减少直接概率拉齐（不取消单视图真值 CE），并用有限、事先定义的互补回复覆盖约束防止总是选到同一前缀。具体形式可取 w_obs(i,a,b)·JSD(p_a,p_b)，其中 w_obs 只来自 **标签不可知、模型预测不可反向决定的可观测 token 覆盖元数据**；既不引入推理 API，也不把语义相似度等价于事实可信度。权重方案是待检验操作化，不是已证实的新算法。
4. **继承/增量**：保留原输入窗口、二分类标签、图模型、DeBERTa-v3-large、训练折记忆、线性融合、JSD 框架和 exact-replay SAM。仅增添 view 构造/损失中的可观测性描述与一致性适用条件；必须对照“固定视图+均匀 JSD”“简单随机回复/截断”“按长度加权”“只做重要性挑选”“取消 JSD”，证明增量超出工程 trick。
5. **必要条件**：原始事件的回复内容、原有 tokenization 配置、同一事件的回复身份到实际 token 覆盖映射（只在允许环境中内部计算；本轮不接触数据）；原始模型内层验证/严格冻结检查点用于诊断。公开仓库**没有**这些逐事件资产，不能现在断言可诊断结果。若 slow tokenizer 无可靠 offset mapping，先用与原 tokenizer 等价的边界重编码核对，不能粗略将原始回复数当作已观察回复数。
6. **停止条件**：若绝大多数四视图在 256 tokens 下几乎相同，或覆盖差异与验证错误/过度自信无稳定关系，**停止该方向**；若普通长度/重采样控制已消除问题，视为工程改进；若减少 JSD 导致总体性能和证据敏感性同时恶化、仅通过调验证超参微弱提高，也停止；若使用可观测性特征出现验证标签/测试信息泄漏则方案作废。
7. **主要风险**：标签恒定的视图即使回复不同也可能有正确且稳定的语义判定；在数据少或源文本强主导时“条件化”可能纯粹减少有益正则。若贡献只是在已有 JSD 前乘手工权重，审稿人合理视为小技巧。要求展现机制性现象、因果对照与稳健性，而不以新缩写挽救方向。

## 4. 候选二（唯一备选）：跨话题的训练近邻适用域

1. **问题**：测试事件虽不在训练库，同一新闻主题/叙事的训练事件仍可成为近邻；参考标签的“高相似度”不必代表对新话题可靠、可迁移的支持。
2. **缺口/前作**：UMER 只用余弦与近邻标签 softmax（model.py 202–232），不建模邻域标签混合、话题分散程度或训练到测试的 topic shift；但 Ren 2021 和 Ran 2023 已做跨话题混合与度量迁移，不能将领域适应或原型称为本项目首创。
3. **机制假设**：先问“错误且高置信的近邻支持是否集中于某些话题/语义近邻标签冲突子群”。若是，拟用**可审计的支持域诊断**（相似度间隔、近邻标签熵、跨训练话题一致程度、是否 out-of-support）对记忆贡献采取保守使用/拒绝，而不是把训练事件标签当外部事实。该机制应与已有可靠性门控、简单缩小 k、去记忆强基线对照。
4. **继承**：图/文本/原 JSD/SAM 不变，仅限训练库诊断与带拒绝的参考支持；外层测试仍不写库。
5. **条件**：可用话题 ID、合法数据与严格话题分组；跨话题留出重新训练、验证和独立阈值选择会**新建协议**，不得直接与原随机五折 0.8988 排名。
6. **停止**：倘若去记忆与有记忆在预设困难组无差异，或拒绝/熵门控不胜过内置 reliability_gate 和简单控制，停止。
7. **风险/排序**：0.03pt 聚合增益不足支持新记忆机制的优先性；训练话题数量少、数据与完整依赖不可公开，诊断成本高于候选一。**仅作为备选**。

## 5. 候选三（暂缓）：真正的早期增量判断

1. **问题**：在 10min/30min/1h 等时窗内回复缺失、增长速度不均，不能依赖完整树。
2. **缺口**：UMER 虽有 240h 时间戳与 source-only 事件，却只正式验证 240h 最终输入；不能将其已有高五折成绩宣传为早期检测。已有 SWAM 2025 的传播率自适应窗口/记忆注意力、SCSNet 2026 的回复贡献和阶段状态是直接强近邻，另有 TGA-CMF 2026 的时间衰减图融合。
3. **机制假设**：借助 UMER 多证据分支，追踪“新回复引入信息时改变预测、无信息时保持判断”，但若仅将现有 SWAM/SCSNet 加到 DeBERTa 上，很难证明新机制。
4. **继承与成本**：部分沿用源帖、回复、图和二分类；需重造时间快照与严格到达时序、考虑何时标签可得。当前资料没有足够证据支持增量超过前作。
5. **必要条件**：每帖可靠时间戳、按时间无未来信息预处理、时窗内验证协议；确认两数据集 240h 预处理不会回看未来结构。
6. **停止**：早期时间戳不可信、source-only 强文本基线难超越、仅靠换窗口增加效果而无独特机制，停止。
7. **风险**：近期直接论文已经覆盖该动机及主要技术；比首选更多预处理与全新比较，故第一轮不推荐启动。

## 6. 首选的最小、先诊断后训练的验证设计（**仅设计，未执行**）

**阶段 D0——零训练反证诊断**。只在原外层训练/内层验证允许的数据上重建四种**实际 tokenizer 输出**，记录每对视图：源帖占用 token、被保留回复身份及 token 份额、两视图 token/回复交集、视图预测 JSD/符号改变，以及固定基线预测的验证错误/置信度。预先固定“充分覆盖”“差异较大”的阈值，或只报告预先设定的分位数箱；不能看外层测试后再划组。控制 source-only / 短对话 / 长对话与 dataset，两种极端下若没有足够有效样本、不出现差异或完全被源长度解释，立即否决；不需要训练新网络。**目前连 D0 都未执行。**

**阶段 D1——若 D0 显示稳定风险，才允许最小机制实验**（需要用户下一轮明确授权）。保留 partition 3090、training 2000、原有效 batch/损失/早停和内层验证，先按既有筛选惯例 fold1+2，再判断是否值得五折；不允许外层测试用于机制选择。主强基线为冻结 UMER（linear + uniform JSD + 四视图），再加无一致性 UMER、文本-only、简单 reply 重采样/截断、长度条件权重、原代码 reliability_gate/conditional_residual 中适用的简单控制。提议机制至少设置 (i) 固定视图+仅条件 JSD，(ii) 互补覆盖选视图+均匀 JSD，(iii) 两者结合；保持同数量的文本前向、相同 token 上限、训练预算与检查点选择标准，禁止用更多推理视图偷偷增加资源。

**评价单位和可证伪输出**：以事件为单位，在**内层验证**比较 Macro-F1、Rumor-F1、Accuracy、负对数似然/校准误差、按预注册覆盖分组的风险差、平均可见回复/token 覆盖及每事件推理成本；给成对错误与分组样本数，避免只选择最有利组。评价新的信息能否合理改变预测与无信息重排是否更稳定时，要保持同事件样本可追溯但**不得公开逐事件日志**。阈值只在验证集拟合，若进行未来新话题/时间分区，其分数与旧五折不可直接相减。所有达标数值与置信区间方法需在实验授权前由团队**预注册**，本轮不凭空写“必须提升 X%”或声称显著性。

**成本**：D0 需现有数据、tokenizer、冻结模型预测/前向（低至中计算，需可用复现资产）；D1 为至少成对的 DeBERTa-v3-large + SAM 训练（高计算，可能约两遍反向的既有成本）；真正早期/跨主题重训成本更高。该公开仓库不含完整运行闭包/检查点。停止门槛以**事先明确的现象、控制对照和无实质退化**为准，不能据外层测试反向设门槛。

## 7. 排序（不是模型投票）

| 指标 | ① 观测覆盖/条件一致性（首选） | ② 话题域内记忆拒绝（备选） | ③ 早期状态机（暂缓） |
| --- | --- | --- | --- |
| 问题证据 | 固定视图、256-token 与 JSD 确认；**损害尚待诊断** | 随机事件划分/近邻库确认；污染尚待诊断 | 240h 非早期确认；现实困难有前作 |
| 近邻机制差异 | 相对 R-Drop/RAGCL/SCSNet 以**观察是否等价**决定一致性；边界窄 | Ren/Ran/内置 gate 已覆盖很多思路，差异弱 | SWAM/SCSNet 直接覆盖阶段机制，差异最弱 |
| 现有资产适配 | 可复用四视图、JSD、同一模型；需未公开 token/原帖映射 | 需话题分组、近邻审计；记忆增益很小 | 需重造时序协议 |
| 先证伪成本 | **低—中**：先不训练检查覆盖/错误关系 | 中—高：训练或话题重划验证 | 高：快照及比较重做 |
| 投稿贡献可解释性 | 有条件：若证据缺失 vs 噪声不变性冲突实证成立且控制排除 trivial | 弱—中，可能退化为简单门控 | 弱—中，易被视为搬运近邻方法 |
| 决策 | **先 D0；若失败立即停** | **至多一项备选** | 暂不启动 |

核心判断：本项目当前最值得购买的不是一个新模块，而是一个明确的**反证机会**：UMER 的多视图一致性改善了总体效果，但是否存在对信息不等价视图的过度约束？若 D0 没有这个现象，第一轮的首选就应主动撤回，回到问题发现，而不是继续硬造模块。
