## 1. 独立结论

**首选：先检验“同一事件标签不等于不同截断观察具有相同信息条件”这一假设，研究 UMER 的一致性应对哪些视图成立。**

这是优先取得问题证据的研究入口，**尚未达到“已有创新方法，可直接扩展正式实验”的状态**。如果只得到一个调小 JSD 权重或按重叠度加权的技巧，而不能证明问题、排除简单对照并解释机制，就应降级为工程改进。这里不建议立即给它起新模型名称。

**备选：新话题下的 source 先验依赖与上下文增量。** 实际需求更强，但直接前作充分、验证和协议改动更大。不能只用 Group DRO、源帖辅助头或残差门控构成新贡献。

**暂缓：早期稳定决策。** 需要重新建立所有输入在截点上的可见性与稳定性评估；直接近邻已覆盖“什么时候判断”和“新回复怎样更新状态”。它不适合通过把现有 240 小时结果裁成几段就迅速改名推进。

排序依据是与 UMER 的可定位联系、现有资产复用和低成本证伪能力，不是断言首选创新性已经优于另外两个方向。

## 3. 候选 A：区分相同观察的不稳定性与互补观察的分歧

### 3.1 问题和假设

UMER 希望对合法序列化保持稳定，这有合理性；但它同时改变了两件事：**信息的排列**和**截断后真正能看到的信息**。

设事件标签为 Y，两个可见输入为 Oa、Ob。同一事件共享 Y，并不推出统计条件后验 P(Y|Oa)=P(Y|Ob)。若 Oa 只有模糊源帖，Ob 还包含对分类有信息的回复，把二者分布强行拉近可能限制 Ob 的学习。这里的“分类信息”不等于事实正确、立场为否认或证据充分；不能把后者作为未经标注的 gold。

假设是：**保留同一观察下随机扰动的一致性，同时减少对不等价观察的无条件一致性，可能更好保留互补回复信息。** 当前正消融说明必须保留原一致性带来的收益，而非简单撤掉它。

### 3.2 已有工作限制了什么

- [R-Drop，NeurIPS 2021，§2.1–2.2](https://papers.neurips.cc/paper_files/paper/2021/file/5a66b9200f29ac3fa0ae244cc2a51b39-Paper.pdf)：对同一输入的两个 dropout 子模型做分布约束。它是相同可见输入的必要强对照；“做两遍一致性”本身没有新意。
- [InfoMin，NeurIPS 2020，§3.1–3.3](https://proceedings.neurips.cc/paper/2020/file/4c2e5eaae9152079b9e95845750bb9ab-Paper.pdf)：视图应保留任务信息的原则已被明确讨论。但其对比学习分析不是 UMER 监督 JSD 的性能定理，不能直接套用证明本项目有害。
- [RAGCL，AAAI 2024，Method](https://arxiv.org/html/2508.07201)：已有针对传播树的重要性增强与图对比学习。因此“保护重要回复的增强”不是新空白；本候选需聚焦实际 token 暴露与预测一致性条件，而非换一种图采样。
- [DCE-RD，KDD 2023，§3.2–3.4](https://arxiv.org/html/2307.09296)：已经选择、聚合多样子图及其补图。仅称“互补证据”“多视图解释”不够；其模型中的反事实目标也不能授权我们把删除回复后的真实事件标签翻转。
- [FoRM，已读 arXiv 2023 版，§IV-B–D](https://arxiv.org/html/2306.11746)：已用标签监督筛选回复并作细粒度推理。新候选不能缩成普通 top-k 回复选择器。其多模态四分类协议与当前二分类并不相同。

**目前差异只是可检验问题的位置更具体，不等于新颖性已经通过。** 跨领域自适应一致性方法仍需补查；本轮检索不能证明没有等价先例。

### 3.3 最小机制候选及其身份

第一版只改文本视图的训练正则，不更换 backbone、图分支、检索和四视图测试聚合，不增加外部知识或语义 teacher。

为每个截断视图记录可见原帖的字符片段及其输入 token 对齐，区分源帖和回复。对回复暴露集合 Ra、Rb，先用 Jaccard q=|Ra∩Rb|/|Ra∪Rb| 建立**简单诊断基线**：

- 完全相同 token 输入按相同观察处理；
- 两者无可见回复时 q=1，不能因空集合误判为互补；
- 一方无回复、另一方有回复时 q=0；
- 源帖不进入回复重叠分数，避免“源帖重复出现”掩盖回复差异；
- q 只是观测重叠，不是语义相关性、证据可信度或充分性。

可测试的最小变体为 `L = L_supervised + lambda * w(q) * JSD(pa,pb)`，先固定 w(q)=q；记录整体正则强度，加入同分布打乱权重和平均强度匹配的常数权重对照。零权重批次明确不施加该项，不用隐含除零/自动加权救分。

这个标量权重**不应直接当创新损失**。它用于判断“正则该不该区分观察”是否值得继续；如果真实暴露条件相比同分布随机权重、调小全局系数或相同输入 R-Drop 思想对照没有增量，停止该机制。只有取得稳定现象后，才讨论是否需要更细的共享/独有信息建模，而不是现在堆第二个模块。

### 3.4 可以复用与必须承认的风险

复用事件标签、文本、原帖映射、tokenizer、图/文本 backbone、训练与选点机制。新增数据仅是程序派生的可见片段映射，不需要 LLM 生成或人工 stance gold。原帖映射和精确 tokenizer 对齐是否能在完整代码闭包中可靠恢复，尚需验证。

主要风险：q 不区分关键与无关回复；低重叠可能恰好是有益增强；不同顺序即使看见相同回复也不完全语义等价；改善可能只来自弱化正则；图/记忆可能已补偿文本缺失；即使验证有效，也可能仍只是常规训练技巧。

本候选研究的是**完整事件可用条件下的文本预算与序列化**。图和记忆仍可看完整允许窗口。不能把它包装成缺回复部署或早期检测，否则所有分支都必须重新遵守可见截点。

## 4. 备选 B：source 先验与上下文增量在新话题中的作用

**问题证据较强，UMER 自身证据仍缺。** [Mu 等，LREC-COLING 2024，§4.1、5.3–5.4](https://aclanthology.org/2024.lrec-main.595.pdf)分析了静态数据切分及 source 依赖；它不直接证明 UMER 有同样幅度的缺陷，也不能把不同 Weibo 版本的数据结论照搬过来。

可检验假设：与仅提升整体准确率相比，让模型在 source-only 预测不可靠的训练条件下更利用源帖—回复关系，可能改善新话题表现。可以研究一个训练期 source-only 偏置专家与上下文残差的分工；但：

- [Clark 等，EMNLP-IJCNLP 2019](https://aclanthology.org/D19-1418/)已有偏置专家与稳健专家联合训练思想，本轮仅读正式页面摘要，不能称首创。
- [FIRM，Findings EMNLP 2025，§2.1–2.2](https://aclanthology.org/2025.findings-emnlp.584.pdf)已有动态发现困难分组及不变学习。
- [GCML，EMNLP 2025，§3–4](https://aclanthology.org/2025.emnlp-main.968.pdf)使用少量目标域标签进行梯度引导的元适应；不等同于完全未见目标域的泛化。
- [GenPromptCL，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/40436)也已覆盖文本域泛化；本轮只读正式页面摘要，未审计其方法公式。

现代码已经有 residual fusion 与 Group DRO，不能把“给 UMER 加残差/去偏”当新方法。最小诊断应对照 source-only、reply-only、完整 UMER 和简单分组重加权，检查不看测试的 topic-heldout 开发协议。reply-only 不是事实验证器，移除 source 的分布变化也不能直接作因果解释。

复用已有标签与回复，无需大模型；但需要核实 PHEME 主题元数据、重复主张分组与类支持，重建训练/验证/记忆分区。改变外层任务时，旧 0.8988 不是同任务对照。若任务差距仅由重复主张、标签偏移或简单重加权解释，或者只得到通用偏置专家迁移，应降级而非扩大训练。成本与创新拥挤程度都高于 A，故仅作备选。

## 5. 暂缓 C：在部分传播条件下作及时且稳定的判断

动机是真实的，但当前 UMER 只有完整 240 小时协议。构造早期输入需要同步重算图、结构统计、事件查询、文本与时间；不能只裁文本而保留未来传播特征。

直接近邻包括：
- [HEARD，NAACL 2022，§4–6](https://aclanthology.org/2022.naacl-main.302.pdf)：已有自动决策时点与预测翻转稳定过程建模。
- [SCSNet，Discover AI 2026，§3.1–3.3](https://link.springer.com/article/10.1007/s44163-026-02227-7)：已有回复贡献组织、状态更新及一致性目标。其“状态稳定但仍响应新信息”的讨论与泛化动机直接压缩本候选空间。
- [2026 limited-observation screening](https://www.mdpi.com/2079-9292/15/15/3330)检索预览还出现单检查点、多观察规模评估；全文打开返回 429，不能据预览判断公式等价。

若继续，差异必须超过“对不同截点预测/添加稳定性 loss”。所需停止准则可考虑未来翻转风险，但这不是天然的新问题。还需核实真实早期数据覆盖、source-only 处理及时间/节点预算差别。HEARD 作者 README 已读，补充 embedding 当前标为不能直接下载；没有据仓库存在断言 BEARD 能立即运行。SCSNet 数据声明为向作者索取，未发现该页直接代码入口。故本轮不推荐先走此路。

## 6. 首选的最小验证草案：先证明问题，再谈新模型

这不是已注册执行协议；参数、预算与效应门槛需在三方讨论后冻结。本轮未执行任何步骤。

### P0：只审查观察，不改模型

仅使用未来获准的训练/开发数据，保持外层测试封存：

1. 检查序列化前后以及 tokenizer 截断后的原帖/字符可见映射；特别检查分隔符、单帖边界、截断片段和空回复。只比较字符串名字不算完成。
2. 输出每事件六对视图的输入相同率、源帖占比、回复覆盖率、q 分布；独立报告 source-only。六对不是六个独立统计样本。
3. 若可见差异很少，或主要差异只是顺序，优先停止“互补暴露”动机；不把问题转移到下一种自由设计的扰动来挽救。
4. 后续获准做小型诊断时，再在冻结模型上测各视图与融合的损失、校准、错误和分歧，按无标签定义的暴露分组报告。单视图变好不能替代最终预测改善；“按真实标签挑最好视图”至多作不可部署的诊断上界。

P0 需要既有文本、tokenizer 和映射处理；公开资料包本身不是可运行数据闭包。没有读取新原始数据，不能保证映射已可用。

### P1：等预算、单变量的机制排除

保留原图/文本编码器、检索库、逐视图 CE、辅助权重、SAM、种子和选点；推理固定四视图。先按原约定 fold1+fold2 作开发筛查，不读外层测试选方法。比较的**对照类别**如下，实际调参次数另列预算：

| 对照 | 回答的问题 |
| --- | --- |
| 原 UMER，lambda=0.5 | 必须保留的历史基准，并在相同闭包中重现基线 |
| 小范围全局 lambda（含零） | 是否只需要调弱正则，而非理解观察条件 |
| 与真实权重同分布、分层后打乱的 q 权重 | 是否只是随机/分组调权或正则强度变化 |
| 真实暴露 q 加权 JSD | 最小待检验机制；显式报告平均权重和有效正则强度 |
| 相同 token 观察的双 dropout 文本一致性 | 排除退回 R-Drop 思想即可解释收益；同时控制 KL/JSD 差别和独有观察的训练曝光量 |

最后一个不是简单启用现有 `--rdrop-weight`：[当前入口 L504–525](../../../reference_code/round_013_joint_trifusion/run_fold.py#L504)禁止 SAM 与 R-Drop 同启用。未来若实现相同观察文本对照，必须在新研究代码中明确其与完整 joint R-Drop 的差异、保持 SAM 重放与监督量，不能偷偷关 SAM 或增加两倍前向。若不能匹配算力与视图曝光，单列成本/数据条件，不能将差值全归因于一致性对象。

可附加固定层上的 CE/JSD 梯度冲突诊断，但梯度夹角只是关联，不是有害因果的证明。实现修改、对照调参同样计入预算，不能只计算主方法一次训练。

### 接受证据与停止条件

- 主结果保留事件级 Macro-F1，并同时报告 Accuracy、Rumor-F1、NLL/校准与推理成本；预定义暴露子群，禁止按结果挑子集。
- 若 q 条件无可重复对应现象，或真实 q 不优于打乱/全局调权，停止“观察条件”解释。
- 若相同输入一致性或普通回复选择已解释全部收益，报告常规对照有效，不升级成新机制。
- 若仅文本分支指标变好、最终融合无稳定增量，或整体退化换来少数个例好看，不进入正式扩展。
- 若改进依赖额外 token、更多视图、关闭 SAM、过滤 source-only 或不公平的基线选择，先视为混杂。
- 数值上最小有意义增量、非劣性界限和成本上限应在执行前商定。当前内层验证规模下几例变化不足以宣布成功；开发筛查后需多种子/独立确认、按事件配对区间，不能把视图对当样本量扩增。
- 即使通过以上验证，仍需补查自适应/不完整视图一致性近邻，才可判断是否足够构成投稿贡献。

## 7. 三个候选的比较与投稿叙事条件

| 维度 | A：观察条件一致性 | B：source 依赖与新话题 | C：早期稳定决策 |
