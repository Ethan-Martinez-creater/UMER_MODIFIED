# UMER-001：R3-C 收敛总结与首项验证建议

日期：2026-10-25。协调者：本机 Codex。本文件汇总三份 R3-C，并给出协调判断；**三方推荐研究问题，不等于创新成立或用户已经批准实验。** 本轮没有处理原始数据、运行模型、连接计算环境、训练或修改原稿。

共同输入为 [f812bf9 资料包](https://github.com/Ethan-Martinez-creater/UMER_MODIFIED/tree/f812bf94cf822cf611a333b74c63648a0fad0a78/discussions/umer-001/convergence_2026-10-25)。三份 R3-C 保存于本目录 `r3c_snapshots/`，仅统一 LF 和末尾单换行；原评论和校验值见 [snapshot_manifest.json](snapshot_manifest.json)。原 R1/R2/R3 与本轮原意见均不改写。

## 1. 可以收束的方向判断

**建议主线：社会反馈偏移下，保留事件相关信息的稳健谣言检测。**

研究问题是：讨论区出现重复放大、离题参与、情绪集聚或群体争执时，检测器能否减少非任务相关反应的影响，同时继续利用与当前事件有关的回复。水军、机器人和历史矛盾是可能成因，不默认拥有主体标签或动机真值。事件级 rumor/non-rumor 任务保留，不把它改写为事实真假证明。

三方均有条件支持这一问题，且均未认定具体机制已准入。意见是在相同新增背景下形成的研究判断，不能把人数一致当成科学证据。

| 参与者 | 相比 R3 的调整 | 本轮保留重点 |
| --- | --- | --- |
| [Codex](https://github.com/Ethan-Martinez-creater/UMER_MODIFIED/issues/1#issuecomment-6394331978) | 收紧共享去重复覆盖范围，强调反应对象与任务相关信息 | 小型人工核验、合法配对、冻结预测审计；方法未闭合 |
| [ChatGPT 网页](https://github.com/Ethan-Martinez-creater/UMER_MODIFIED/issues/1#issuecomment-6394364686) | 原证据保留型一致性不再单独承担主线 | 可见性/预算控制，正常有效回复对照，人工核验反馈类别 |
| [Zcode](https://github.com/Ethan-Martinez-creater/UMER_MODIFIED/issues/1#issuecomment-6394382492) | 新话题可靠性降为备选，纠正信息类型归因与训练次数 | 重复和跨事件移植的程序化压力测试、通道审计与节点数控制 |

**至多一个备选**：新话题部署中的证据可靠性问题。它不自动获得实验准入；跨话题门控的增量及成本仍不明确。主线不成立时也不自动启动备选训练。

**原观察覆盖/一致性问题**：保留为文本可见性和计算预算的控制，不与主线拼成第二套训练机制，也不并行立项。

## 2. 成功后应留下的贡献

问题证据：验证哪些社会反馈变化会影响判断，定位单路主导或多路共同变化，并排除节点数、文本挤占等简单解释。

机制证据：形成具体、可复核且区别于已有工作的处理机制；正面比较统一简单去重、源帖引导过滤、相同预算的分路处理与常规稳健训练。当前尚未完成此论证。

能力证据：在预先冻结且未用于方法选择的偏移条件下减少错误，同时保留事件相关回复的帮助，报告干净能力、成本和不确定性。干净集总体指标可以持平；仅新增指标、注意力图、一个脆弱性图谱或少量好案例不自动支撑论文。

机器人传播、协同行为和群体互动研究支持现实动机；MALCOM、AARD、ClaHi-GAT、情绪解耦和 Conflict and Bot Features 等已压缩宽泛新颖性。不能再以“首次抗评论攻击/筛选回复/利用冲突或情绪”论证创新，详见前一资料包的证据说明。

## 3. 仍有分歧，以及本次协调取舍

以下为协调者在阅读三份意见后的修订，**不冒充三方已再次共同确认的协议**。

### 跨事件移植不保证语义无关

接受 Zcode 建议，把移植作为程序化压力测试候选；不接受“跨事件先验保证无关”。不同事件可能涉及同一主张、人物或通用表达；移植也可能产生明显不自然的接话。没有独立核验时只能称“跨事件移植”，不能把它当作离题、情绪偏移或群体矛盾的真值。

因此采取两层证据：程序化扰动先测输入敏感性；若要作语义相关性/情绪层解释，需小型独立人工核验或其他可审计的既有标签。强情绪、词面不相似或账户同步都不能单独定义恶意。关于真实协同行为很少逐字复制的频率判断，本轮没有采纳为已核实事实。

### 多路共同偏移是一项机制假设

若只有文本或图支路主导，否定的是“必须跨路共同处理”的主张，不自动否定社会反馈可靠性这个问题。反之，多路同向变化也不证明共享分组优于简单处理。不得强求每个事件三路都变坏，或只保留满足该现象的案例。

正式线性融合下可分解固定参数的 rumor logit 边际变化；这不是新归因算法、概率独立证明或超加性交互证据。固定模型上的输入处理也不等于相同配置独立重训的消融效果。

### 方法与时间预算仍未定

共享去重、反应对象区分、可靠性门控目前都只是构想，不预先锁定其中一个。Zcode 已把备选改为一个留出话题×三配置，计数修正保留。

首项扰动条件必须逐项列清。若干净输入，加复制、移植、分散追加各两档，就是七条件；不能继续套五条件的 8,000 序列估计。额外过滤、模型调用、特征重算和人工复核均需单列。材料没有实测吞吐，因此不采纳“2–4 天工程＋单卡日前向”为工期承诺。

## 4. 推荐的一项首项验证：配对社会反馈压力审计

**目的**：决定该问题在现有数据和 UMER 上是否值得投入方法研究，不是直接证明新防御有效。下列规模为协调建议，尚非已授权执行或完成预注册的协议。

### 先满足输入与测量准入

核实源帖/回复、父子与时间关系、原始到文本/图/节点语义的映射、正式 tokenizer 与冻结模型是否可用。必须能从同一个修改后事件重建全部输入；仅改文本而图和检索仍含原上下文，不是合法的共同扰动。缺失则 NOT_READY，不能写作方法被证伪。

先以每语料至多 10 个开发事件、每事件至多两组候选回复对试核规则；两名能理解对应语言的审核者独立判断，至多约 80 份配对审核，另计上下文阅读与分歧复核。标注反应对象、事件相关补充和情绪维度，不标注恶意身份，不判断世界事实真假。核验者不看模型输出或事件类别挑案例。操作规则和一致性门槛先定；样本小，不能以试核一致就宣称已得到可靠大基准。

人员未落实时，不把两个智能体的判断称为独立人工真值；此时只能保留明确标注局限的程序化压力测试，情绪/群体解释不准入。

### 再做小规模冻结模型筛查

建议上限为每语料 50 个开发事件，最多 100 个独立事件。固定抽样规则，source-only、不可匹配或容量不足事件记录比例，不从原任务总体中静默过滤。为测正常新回复的作用，基底需按固定规则预留真实回复；预留内容不能提前进入该查询的图、结构统计或检索查询。此为受控观察子集，不宣称早期部署能力。

初始只用单条追加预算，候选条件如下；不满足语义、时间/挂接或数量/长度匹配的条件记为缺失，不硬造样本：

| 条件 | 身份与用途 |
| --- | --- |
| C0 基底 | 配对参照，固定源帖与任务含义 |
| C1 同事件回复精确复制 | 重复放大探针 |
| C2 从允许训练池移植回复 | 程序化压力探针，语义无关性未知；选取不用查询真值 |
| C3 核验后主要针对其他对象的反应 | 测非任务相关反馈；情绪单列，非恶意标签 |
| C4 预留的事件相关、内容不同回复 | 检查有效上下文利用；相关不自动等于有帮助 |
| C5 数量/长度匹配的同事件随机追加 | 选择方式和规模控制，不称纯无信息对照 |

对每条件从相同修改后事件重算四视图、图和检索查询；训练标签记忆库固定，不写入查询或其变体。训练样本若作查询，必须排除自身及相关变体；优先使用合法内层开发查询。

测量最终配对损失、错误变化、置信变化、各路加权边际变化及 token/节点暴露。**错误到正确的翻转不能算攻击成功。** 以事件为推断单位，不把多个条件当独立样本。标签只用于明确的开发层评价，不按旧测试结果选择条件或阈值。开发验证参与过检查点选择，仍是探索。

先比较原模型与简单全路去重、源帖引导的粗过滤下的输入敏感性；这些是诊断控制，最终方法比较需要匹配训练条件。单靠相似度过滤不能当相关性真值。若未获得平衡、可核验条件，不声称分离了情绪的因果影响。

### 成本和结果分支

无重训；需人工核验、数据工程和新前向。示例上限：100 事件×6 条件×4 视图为 2,400 条文本序列；若额外两种预处理均完整前向则最多约 7,200 条，另计图、检索、特征重算及任何额外模型成本。这不是 GPU 时长估计。先核资源和条件覆盖，再冻结实际矩阵。

- **继续**：合法匹配条件存在，变化造成超过预定最小效应的错误/损失影响，正常相关回复的作用可测，且不能全部归因于预算、节点数或简单控制。只获得问题证据，之后仍需新颖性和方法排除。
- **否决某机制**：单路主导、简单去重/过滤解决，或独立处理足以解释。不得直接宣称跨表示共享机制必要。
- **停止主线投入**：在可支撑规模与语义合法条件下，未见有意义问题，或可行方案始终等同成熟处理、没有新增能力证据。
- **NOT_READY**：输入闭包、人力或合法对照不足。披露缺口，不当作科学否证，也不自动恢复大模型路线或启动备选训练。

最小效应、干净能力非劣要求、抽样和停止规则须在分析预测之前确定。确认用新事件/时段或披露接触历史的预注册重评估；旧数据不冒充完全独立 holdout。
