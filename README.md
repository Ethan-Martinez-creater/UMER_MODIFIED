## UMER 已完成的工作

UMER 是事件级 `rumor / non-rumor` 二分类模型，输入为源帖及 240 小时内回复。联合使用传播表示、多视图 DeBERTa 文本和训练折内近邻标签上下文，通过决策级线性融合、辅助监督、跨视图一致性及 exact-replay SAM 训练。

| 数据集 | 事件数 | Accuracy | Macro-F1 | Rumor-F1 |
|---|---:|---:|---:|---:|
| PHEME | 6,425 | 0.8988 | 0.8925 | 0.8666 |
| Ma-Weibo | 4,664 | 0.9689 | 0.9689 | 0.9694 |

以上是既有正式五折结果，不是本次重新训练或测试所得。可读的[逐折聚合 JSON](results/README.md)保留原有数值与字段。部分基线存在测试参与选择、事件过滤或未完成全部折等协议差异，详见[原稿配套审计](manuscript/audits/)。

## 必须保留的边界

- UMER 不使用大模型推理或开放网络事实证据；训练折近邻标签上下文不能称为开放事实核查。
- 每折单个联合检查点仍包含验证/测试时四文本视图 logits 平均。
- `rumor` 不是 `false` 的同义词；事件随机五折不是跨话题留出；240 小时输入不是已验证的早期检测。
- 记忆分支总体 Accuracy 增益约 0.03 个百分点，不夸大其作用。
- 后续大模型探索尚未确立第二项成果；格式合法、工程完成或小样本诊断不等于有效性或创新性成立。

## 仓库内容与来源

- `docs/`：整理后的背景、历史架构与实验说明、探索边界。
- `manuscript/`：原稿文本快照；科学正文没有在此次归档中修订。
- `reference_code/`：五份关键源码阅读快照，**不构成可运行依赖闭包**。
- `results/`：正式模型及四类消融的六份汇总 JSON，不包含逐事件预测。
- `SOURCE_MANIFEST.json`：原材料相对标识、来源与发布副本 SHA256、处理说明。
- `.github/ISSUE_TEMPLATE/`：后续研究问题模板，模板本身不启动研究。
