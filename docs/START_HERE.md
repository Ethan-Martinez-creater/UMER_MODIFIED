# 统一研究背景

整理于 2026-10-25。本文供无法访问本机材料的参与者建立背景；只描述已知事实，不提出新的改进路线。

## 1. 工作之间的关系

总体研究围绕社交网络谣言检测。UMER 是已完成的第一项模型工作，有冻结实验、代码和英文论文稿。之后的大模型探索旨在寻找第二项可验证工作，目前尚未形成已经确立的第二项创新成果。UMER 论文、后续探索与系统实现是相关但不同的工作，不混写成果。

这个新仓库用于统一背景和后续讨论。旧研究目录与原始论文是只读来源；整理副本不赋予任何参与者修改旧文件或接续历史实验的权限。

## 2. UMER 的任务和结构

- 输入：一个源帖及其 240 小时窗口内的回复构成的事件；输出：事件级 rumor/non-rumor。
- 图表示：14 维非文本与传播特征的节点 Set 编码器，以及节点内容/结构投影后的一层节点 Transformer；两类事件读出在图分支内融合。
- 文本：共享 DeBERTa-v3-large；full/reversed/even/odd 四种确定性会话序列化；源帖恒在首位；训练抽取两个不同视图，验证/测试平均全部四视图 logits。
- 跨事件上下文：从允许的训练事件记忆库检索 top-31 语义近邻，温度 0.05，对近邻标签加权并取 rumor log-odds；训练查询排除自身，验证/测试事件不写入记忆库。
- 决策融合：两维图 logits、两维文本 logits、一个上下文 logit 经 Linear(5,2) 得到最终预测。
- 监督：最终分类损失、图/文本辅助监督（各 0.15），以及权重 0.5 的跨视图广义 JSD。
- 优化：有效累积批次上的 exact-replay SAM，使两遍使用相同微批次、视图及随机状态；训练开销不等于推理开销。

更细的维度、公式及源码定位见 [架构记录](UMER_MODEL_ARCHITECTURE.md) 和 [源码入口](../reference_code/README.md)。

## 3. 冻结协议与证据

partition seed 3090、training seed 2000；事件级分层五折；外层训练池内再留出验证集，用于检查点和阈值选择。物理 event batch 4、累积 16、有效 batch 64、最多 30 epochs、patience 7、SAM rho 0.05。

PHEME 的 Accuracy/Macro-F1/Rumor-F1 为 0.8988/0.8925/0.8666；Ma-Weibo 为 0.9689/0.9689/0.9694。PHEME 去文本、去一致性、去图、去记忆的 Accuracy 分别为 0.8601、0.8895、0.8940、0.8985。此处沿用既有记录，不声明本次重新验证。

## 4. 不要混淆的结论

1. 事件 rumor 标签不直接等于事实为假，non-rumor 也不是系统对每条内容的事实证明。
2. 同一外层事件分区不保证各基线预处理、选择协议和测试总体一致。
3. 单检查点不意味着只做一个文本视图的推理。
4. 早期失败只适用于对应任务、协议、数据与门槛，不能推出所有大模型或所有传播结构无效。
5. NOT_READY 表示资源或材料不足，不能改写为模型机制已被证伪。
6. 后续事实核查检索候选没有与 UMER 自动组成一个已经验证的统一系统。
