# 公开资料边界与来源说明

## 本次发布范围

整理日期：2026-10-25。目标仓库经元数据读取确认当前为公开仓库。使用定向文件白名单整理，不进行旧工作区全量复制，不上传旧 Git 历史或本轮工具日志。

本次只发布：
- 模型任务、架构和冻结训练协议等科研说明；
- 六份不含逐事件记录的既有结果汇总；
- 原稿 TeX 文本、BibTeX 和经过处理的历史审计；
- 五份用于理解结构与机制的源码文本；
- 研究状态快照、材料差异、阅读和讨论约定。

## 没有发布的内容

- 任何计算设备的连接地址、端口、登录账户、部署目录、连接脚本、认证机制细节或实时资源状态；
- API 凭据、访问令牌、密码、环境变量文件及工具账户状态；
- 私有绝对路径、原始会话和工具日志、进程或任务执行记录；
- 原始社交媒体帖子、用户/事件标识、标注清单、逐样本预测或训练样本；
- 数据集、预训练权重、训练检查点、缓存和大型附件；
- 原部署指南、资源位置清单、环境锁定文件或带历史执行授权的完整交接文档；
- 未检查元数据的 PDF、图像、办公文件和原参考论文。

不要把此排除清单理解为这些文件可以在以后自动上传。新增内容仍按用户授权、必要性和实际内容逐项检查。

## 处理方法

- 新写的概述只采用本会话已经读取的事实，并注明历史与未验证边界。
- 原稿 main.tex、references.bib 和结果 JSON 保留原有正文/数值，只规范换行并确保末尾换行。
- 训练入口两个私有部署默认值替换为通用相对占位；配套审计的私有定位信息替换为逻辑来源标识。
- 架构/实验文档移除私有部署指南链接和相关操作说明；历史探索与审计增加范围标记。
- 没有更改模型机制、论文公式、指标、历史失败门槛或关闭结论。
- 对所有待上传文本检查私有路径、部署标识、地址、邮箱、常见密钥格式和凭据赋值；公开学术链接与文献作者姓名保留。
- 发布前核对 JSON 可解析、结果均值与展示数字一致、内部 Markdown 文件链接可定位及文件校验值。上述检查不是模型有效性测试。

.gitignore 只是辅助排除规则，不能替代内容检查。上传使用固定清单，不使用整目录递归上传或自动 git add 全部文件。

## 来源与证据等级

SOURCE_MANIFEST.json 为每个文件提供发布文本 SHA256。来自原材料的文件另记录：
- 抽象来源区域（research_archive 或 manuscript_archive），不包含机器位置；
- 原文件的相对标识与修改时间（仅作为版本定位线索）；
- 原文件 SHA256；
- 发布路径和处理说明。

文件修改时间不保证就是研究完成时间，也不等同于经过认证的版本时间。摘要中的后续终态与计数部分来自用户在本会话给出的 2026-10-24 历史交接，并由已经读取的指定材料提供局部佐证；没有重新核查所有原始产物。

本次没有连接计算设备、执行论文编译、模型推理或训练、调用推理 API，亦没有重新核验所有学术链接、当前会议要求或每个实验产物。数据集、模型与文献的原有许可仍各自适用。
